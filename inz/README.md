# Rozetka Sentiment Analysis

Веб-додаток для аналізу тональності відгуків на товари з Rozetka.com.ua з використанням Flask, Selenium та машинного навчання.

## 📋 Опис

Додаток автоматично збирає відгуки з Rozetka, аналізує їх тональність на основі оцінок та тексту, і візуалізує результати через інтерактивні діаграми.

### Основні можливості

- ✅ **Автоматичний збір відгуків** - використовує Selenium для клікання кнопки "Показати ще"
- 📊 **Аналіз тональності** - класифікація відгуків (Позитивні/Нейтральні/Негативні)
- 📈 **Візуалізація даних** - 6 типів діаграм та графіків
- 🔍 **Виділення ключових слів** - TF-IDF аналіз найважливіших слів
- ☁️ **Хмари слів** - візуалізація частотності слів
- 🎯 **Рекомендація до покупки** - автоматична оцінка на основі аналізу

## 🚀 Швидкий старт

### Вимоги

- Python 3.8+
- Google Chrome (для Selenium)
- Віртуальне середовище Python

### Встановлення

1. **Клонуйте репозиторій**
   ```bash
   git clone <repository-url>
   cd inz
   ```

2. **Створіть віртуальне середовище**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   ```

3. **Встановіть залежності**
   ```bash
   pip install -r requirements.txt
   ```

### Запуск

```bash
python app.py
```

Відкрийте браузер: `http://127.0.0.1:5000`

## 📖 Використання

1. Скопіюйте посилання на сторінку товару з Rozetka
2. Вставте URL у поле вводу
3. Натисніть "Аналізувати"
4. Зачекайте 30-60 секунд (залежно від кількості відгуків)
5. Переглядайте результати аналізу

### Приклади URL

```
https://rozetka.com.ua/ua/apple-iphone-14-128gb-blue/p352486503/comments/
https://rozetka.com.ua/ua/sony-wh1000xm6b-ce7/p512325929/comments/
```

## 📊 Діаграми та візуалізації

### 1. Статистика
- Всього відгуків
- Середня оцінка (1-5 зірок)
- Кількість позитивних/нейтральних/негативних відгуків

### 2. Діаграми
- **Розподіл тональності** - кругова діаграма
- **Розподіл оцінок** - стовпчаста діаграма (1-5 зірок)
- **Розподіл довжини відгуків** - лінійний графік
- **Рекомендація до покупки** - gauge-діаграма (0-100%)

### 3. Текстовий аналіз
- **Топ-10 слів** - окремо для позитивних та негативних відгуків
- **Хмари слів** - візуалізація найчастіших слів

## 🛠️ Технології

### Backend
- **Flask** - веб-фреймворк
- **Selenium** - автоматизація браузера для збору даних
- **BeautifulSoup4** - парсинг HTML
- **pandas** - обробка даних
- **scikit-learn** - TF-IDF для виділення ключових слів

### Візуалізація
- **matplotlib** - створення графіків
- **seaborn** - стилізація діаграм
- **wordcloud** - генерація хмар слів

### NLP
- **pymorphy2** - морфологічний аналіз (опціонально)
- Власний список з 375+ українських стоп-слів (включає назви брендів, моделей та загальні терміни)

## 🔍 Як це працює

### 1. Збір даних (Selenium)
- Відкриває сторінку товару в headless Chrome
- Чекає завантаження відгуків
- Клікає кнопку "Показати ще" до 10 разів
- Парсить HTML та витягує текст, оцінки, дати

### 2. Аналіз тональності
- **5 зірок** → Позитивний
- **4 зірки** → Позитивний
- **3 зірки** → Нейтральний
- **1-2 зірки** → Негативний

### 3. Рекомендація до покупки
```
Оцінка = (Середня_оцінка / 5 × 60%) + (% Позитивних × 40%)
```

- **80-100%** → Дуже рекомендуємо
- **60-79%** → Рекомендуємо
- **40-59%** → Нейтрально
- **0-39%** → Не рекомендуємо

## 🐛 Відомі обмеження

- Працює тільки з Rozetka.com.ua
- Потребує Google Chrome
- Selenium може бути повільним (30-60 сек)
- Деякі відгуки можуть мати 0 зірок (помилка парсингу)
